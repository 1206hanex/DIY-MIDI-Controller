# DIY-MIDI-Controller
Adafruit Feather RP2040-based USB MIDI controller.  

This is a personal project that I hope will teach me the basics in microcontroller programming, electronics, and circuit & hardware design.

## Project Goal

The end goal of this project is to become a "budget" solution to enable MIDi capabilities onto my effects pedalboard. I want to be able to cycle through my patches, jump to a specific patch, and turn effects on/off using MIDI messages.
